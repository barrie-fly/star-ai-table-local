## 1. 快速开始

三步上手：

1. **注册账号**：打开工作台登录页，切换到「注册新账号」，填写用户名、邮箱与验证码。
2. **创建项目**：注册后会自动创建一个默认项目，也可在项目管理模块新建。
3. **生成页面**：进入云工作站，用左侧元素面板手动搭建，或在右侧 AI 助手输入指令自动生成。

> 提示：等级越高，可创建项目数与每日 AI 调用额度越高。

## 2. 账号注册与登录

### 2.1 注册账号

1. 打开工作台（默认 `http://localhost:5100`）。
2. 点击「注册新账号」。
3. 填写：
   - **用户名**：3-32 位，字母 / 数字 / 下划线 / 中文
   - **昵称**（可选）
   - **邮箱**：点击「取验证码」，输入收到的邮箱验证码
   - **密码**：≥8 位，含大小写 / 数字 / 符号
4. 点击 **注册**。

> 密码强度规则实时校验：长度、大写、小写、数字、符号 5 项全满足才可提交。

### 2.2 登录

1. 输入用户名或邮箱。
2. 输入密码。
3. 点击 **登录**。

如已启用 MFA，还需输入第二步验证码（邮箱验证码或认证器 App 动态码）。

### 2.3 忘记密码

联系平台管理员重置密码。

### 2.4 下载桌面客户端

访问下载页 `https://<你的站点>/download.html`，下载 Windows 客户端。首次登录需填写可用的服务端地址（默认 `http://127.0.0.1:5100`）。

## 4. 功能模块说明

### 4.1 项目管理（PM）

- **项目仪表盘**：项目列表、统计卡片、创建项目（可套模板）。
- **项目详情**：阶段进度、任务面板（列表/看板/甘特三视图）、成员管理。
- **审批中心**：我的待办、审批配置。
- **模板与授权**：项目模板、权限模板、临时授权。

### 4.2 AI 集成工作台

- 模型、Agent、工具链、知识库与协作收敛在同一处。
- 支持代码生成/补全/解释/审查/修复。
- 代码库智能问答（索引 + RAG + 本地模型）。
- 离线可用：内置 Ollama 运行时，数据不出设备。

### 4.3 物理模拟

- 内置场景预设：自由落体 / 弹簧振子 / 弹性碰撞等。
- 运行仿真后支持回放、轨迹与速度箭头显示。
- 3D 可视化：`/phys3d.html`，支持相机控制、光照调节、图表、数据导出（CSV/JSON）、WebM 录制。

### 4.4 文件工具（FileTools）

- 编码检测/转换（GBK、UTF-16 等）。
- 文件加解密（对称/RSA 混合/哈希）。
- 压缩包创建/解压（zip / tar.gz，支持密码）。
- 网络分包构造/解析。

### 4.5 神经网络与集群协同

- **神经网络模拟**：网络结构、神经元激活状态实时可视化。
- **Agent 编队**：多 AI 集群通信拓扑。
- **数据总线**：数据流向可视化。
- **工作流编排**：任务编排，支持项目统筹。

### 4.6 创作台

- **矢量编辑器**：AI 面板驱动的矢量绘图，产物一键入库。
- **电路模拟设计**：SPICE 网表导出 + Ollama 本地诊断。
- **音视频工作室**：素材入库管理。

## 5. 常见操作步骤

### 5.1 创建项目

1. 进入「项目仪表盘」。
2. 点击 **创建项目**。
3. 填写名称、描述、负责人、截止日期。
4. 可选套用项目模板。
5. 点击 **创建**。

> 消耗：2 钱包积分。

### 5.2 调用 AI 助手

1. 按 `Ctrl+B` 打开助手面板。
2. 输入指令（如「帮我生成一个登录页」）。
3. 选择模型（不同模型倍率不同，消耗积分不同）。
4. 等待生成结果。

> 消耗：基础 1 积分 × 模型倍率。调用失败自动退还。

### 5.3 查看我的任务

1. 进入项目详情 →「任务面板」。
2. 切换列表 / 看板 / 甘特视图。
3. 点击任务可查看详情、修改状态、设置进度。

### 5.4 提交反馈

1. 进入「反馈」页。
2. 提交缺陷或功能建议。
3. 被采纳后自动发放积分（缺陷 20 分 / 建议 30 分）。

### 5.5 申请权限

1. 在需要权限的功能页面点击「申请权限」。
2. 选择权限点、填写理由。
3. 提交后进入审批流，可在「我的申请」查看状态。

## 7. 积分与等级

### 7.1 等级

| 等级 | 名称 | 所需积分 | 每日 AI 调用 |
|---|---|---|---|
| 1 | 见习 | 0 | 20 |
| 2 | 入门 | 100 | 100 |
| 3 | 熟练 | 300 | 300 |
| 4 | 资深 | 800 | 1000 |
| 5 | 专家 | 2000 | 不限 |

### 7.2 获取积分

| 途径 | 积分 |
|---|---|
| 每月赠送 | 100（当月过期） |
| 每日登录 | 10 + 连续奖励 5/天（7 天有效） |
| 社区贡献 | 漏洞 500 起 / GitHub 200 起（指数升级） |
| 充值 | 1 元 = 1 积分（人工审核） |
| 反馈被采纳 | 缺陷 20 / 建议 30 |

### 7.3 查看积分

- 客户端：进入「钱包」页查看余额与流水。
- 等级进度：「等级与进度」页查看升级进度条。

### 7.4 兑换算力

1. 进入「算力与用量」→「算力兑换」。
2. 选择兑换档位（200 积分 → 500 次，700 → 2000 次，1800 → 6000 次）。
3. 点击 **兑换**，即时到账。

## 8. CLI 快速上手

```bash
localserve shell                  # 进入交互式 Shell
localserve file list .            # 列出文件
localserve phys simulate --preset spring --seconds 2   # 物理仿真
localserve skill invoke ai.parse  # AI 启发式解析
localserve backup run             # 数据库备份
```

常用退出码：`0` 成功 · `1` 一般错误 · `2` 用法错误 · `3` 未找到 · `4` 危险命令拒绝 · `70` 内部错误。

## 9. 常见问题解答

**Q：AI 功能必须联网吗？**
A：否。网关健康时用 AI 增强；离线时 `ai suggest` 回退离线词表、`ai explain` 回退结构摘要、`ai fix` 回退规则引擎。

**Q：忘记密码怎么办？**
A：联系平台管理员重置。

**Q：如何提升等级？**
A：通过每日登录、创建项目、画布操作、AI 对话、提交贡献等行为获取等级积分，累计达到阈值自动升级。

**Q：积分不够用怎么办？**
A：每日登录 + 连续签到、提交社区贡献、反馈建议、充值均可获取积分。

**Q：3D 物理可视化页面加载失败？**
A：3D 页依赖 CDN 加载 Three.js；离线环境会显示「Three.js 加载失败」提示页，请检查网络或改用内置 2D 可视化。

**Q：任务无法拖拽到目标列？**
A：看板拖拽受状态机约束，非法流转会被拒绝并回弹。请按状态机规则流转。
