## 1. 角色与权限模型

### 1.1 项目级四角色

| 角色 | 权限 |
|---|---|
| `Viewer` | 只读：查看项目详情、阶段进度、成员、任务列表 |
| `Member` | Viewer + 编辑项目/阶段、创建与更新任务、设置任务进度 |
| `Manager` | Member + 归档项目、成员管理 |
| `Admin` | 全部项目权限，含删除、审批配置、模板管理 |

### 1.2 平台权限点

PM 模块在权限目录注册 13 个权限点（分组「项目管理」），由平台管理员在角色权限矩阵中分配。API 双层门禁 = 平台权限点 + 项目级角色。

### 1.3 非成员访问规则

非项目成员访问项目详情/任务接口返回 404（防探测）；越权操作返回 403。

## 3. 项目创建

### 3.1 创建空白项目

1. 进入「项目仪表盘」。
2. 点击 **创建项目**。
3. 填写：
   - 项目名称（必填）
   - 项目描述
   - 负责人
   - 截止日期
4. 可选：套用项目模板（自动生成预置阶段集合）。
5. 点击 **创建**。

> 说明：创建者自动成为项目 owner；创建项目消耗 2 积分（钱包积分，由客户端本地账本扣减）。

### 3.2 使用项目模板创建

1. 进入「项目仪表盘」→「创建项目」。
2. 在模板列表选择目标模板。
3. 确认预置阶段（可增删）。
4. 点击 **创建**。

### 3.3 项目状态说明

项目状态包括：`Active`（进行中）、`Completed`（已完成）、`Archived`（已归档）等。状态推进由项目管理员操作。

## 4. 成员管理

### 4.1 添加成员

1. 进入项目详情 →「成员管理」。
2. 点击 **添加成员**。
3. 搜索用户（平台账号）并选择。
4. 分配项目角色（Viewer / Member / Manager / Admin）。
5. 点击 **保存**。

### 4.2 调整角色

在成员列表中找到目标成员，点击角色下拉框修改，保存后即时生效。

### 4.3 移除成员

在成员列表中找到目标成员，点击 **移除**。

> ⚠️ **注意**：移除成员后，该成员立即失去项目访问权；其名下未完成任务需重新指派。

### 4.4 批量添加

「成员管理」支持批量输入多个用户名一次性添加，并统一分配默认角色。

## 5. 任务分配与进度跟踪

### 5.1 创建任务

1. 进入项目详情 →「任务面板」。
2. 点击 **新建任务**。
3. 填写：
   - 标题（必填）
   - 描述
   - 优先级（低/中/高）
   - 负责人（assignee）
   - 开始日期、截止日期
   - 所属阶段
4. 点击 **创建**。

### 5.2 任务状态流转

状态机合法流转：

| 当前状态 | 可流转到 |
|---|---|
| `Todo` | `InProgress` / `Cancelled` |
| `InProgress` | `Todo` / `Blocked` / `Done` |
| `Blocked` | `Todo` / `InProgress` / `Cancelled` |
| `Done` | `Todo` / `InProgress` |
| `Cancelled` | `Todo` / `InProgress` |

- 流转到 `Done` 时进度自动置 100 并记录完成时间。
- 非法流转会被状态机拒绝（HTTP 400）。
- 自转视为幂等合法。

### 5.3 三种视图

任务面板提供三种视图（标签页切换，选择持久化于本地）：

- **列表视图**：表格展示，支持状态快捷流转、进度 +10、删除。
- **看板视图**：按状态四列（待办/进行中/已阻塞/已完成）+ 底部「已取消」折叠区；卡片可拖拽换列，drop 后自动调用状态流转接口。
- **甘特视图**：按天时间轴展示已排期任务，今日橙色竖线；未排期任务单列下方；前置依赖未完成的任务以红色虚线框标记。

### 5.4 设置依赖

1. 打开任务详情。
2. 在「依赖」区域添加前置任务。
3. 系统自动检测成环与自依赖，非法依赖返回 400。

### 5.5 我的任务

项目成员可在「我的任务」（`/api/pm/my-tasks`）查看分配给自己的任务，按截止日期排序，支持按状态过滤。

## 6. 项目阶段与加权进度

### 6.1 阶段管理

1. 进入项目详情 →「阶段」。
2. 点击 **添加阶段**。
3. 填写阶段名称、权重、计划起止日期。
4. 保存后自动参与总进度计算。

### 6.2 加权进度算法

- 总进度 = 各阶段进度 × 权重 的加权平均。
- 无阶段时进度为 0。
- 阶段进度越界自动钳制到 [0,1]。

### 6.3 进度更新

- 阶段进度：在阶段卡片直接修改百分比。
- 任务进度：`PUT /api/pm/tasks/{id}/progress`，0-100；≥100 自动流转 `Done`。

## 7. 审批流配置

### 7.1 配置审批链

1. 进入「审批中心」→「审批配置」。
2. 选择业务类型（bizType）。
3. 配置审批人序列（一级、二级……）。
4. 设置升级时限（默认 24 小时）。
5. 选择通知方式（站内信/邮件）。

### 7.2 审批流转规则

- 一级批准后自动推进到二级。
- 任一级驳回立即终止实例。
- 末级批准后实例完成。
- 已决策实例不可重复决策。
- 非指派审批人不能决策（越权拒绝）。

### 7.3 我的待办

进入「审批中心」→「我的待办」查看待审批事项，点击查看详情后选择 **同意** / **拒绝** 并填写意见。

## 8. 模板与临时授权

### 8.1 项目模板管理

1. 进入「模板与授权」→「项目模板」。
2. 点击 **新建模板**，配置预置阶段集合。
3. 保存后可用于快速创建同构项目。

### 8.2 权限模板

权限模板预置权限点集合，可应用到用户：

1. 进入「模板与授权」→「权限模板」。
2. 选择模板 → **应用**。
3. 输入用户与角色代码，一键完成授权。

### 8.3 临时授权

1. 进入「模板与授权」→「临时授权」。
2. 选择用户、权限点、过期时间。
3. 保存后立即生效；过期后自动置 `revoked`（后台每 10 分钟清扫）。

## 9. 资源调配

### 9.1 跨项目查看成员负载

项目仪表盘提供成员维度统计，可查看成员参与的项目数量与任务负载。

### 9.2 事件桥与外部系统联动

PM 事件通过发件箱模式投递到 AgentCluster / WebHook：

- `project.created` / `project.updated` 自动同步到 AgentCluster 控制面。
- WebHook 订阅可接收 `task.created` / `task.updated` / `task.status.changed` 等事件。
- 投递失败自动指数退避重试（<5 次），超限置 `failed`，可在事件管理页重放。

### 9.3 事件重放

```bash
# 需 pm.admin.events 权限
POST /api/pm/admin/events/{id}/replay
```

## 10. 项目归档与删除

### 10.1 归档项目

1. 进入项目详情 → 右上角菜单 → **归档**。
2. 确认归档（需 Manager+ 权限）。
3. 归档后项目进入只读状态，成员不可再编辑。

### 10.2 删除项目

1. 进入项目详情 → 右上角菜单 → **删除**。
2. 确认删除（软删除，数据保留但不可访问）。

> ⚠️ **注意**：删除为软删除，记录保留在数据库；如需彻底清除请联系平台管理员。

## 11. 最佳实践

1. **模板先行**：同类型项目使用项目模板，保证阶段结构一致。
2. **角色最小化**：默认授予 Member，仅在需要归档/审批配置时提升为 Manager。
3. **任务明确负责人**：每个任务必须有 assignee，避免「无主任务」。
4. **善用依赖**：关键路径任务设置依赖，甘特视图可清晰识别阻塞。
5. **及时推进状态**：任务完成后及时流转 `Done`，保持看板与进度准确。
6. **审批链分级**：敏感操作配置两级审批，降低误操作风险。

## 12. 常见问题

**Q：为什么成员看不到项目？**
A：可能未添加为项目成员，或平台权限点未分配。请检查「成员管理」与「角色权限」。

**Q：任务无法流转到目标状态？**
A：状态机限制了非法流转（如 `Todo→Done` 直接跳转会被拒绝）。请先流转到 `InProgress` 再 `Done`。

**Q：非成员访问项目返回 404？**
A：这是防探测设计。请由项目管理员添加成员。

**Q：事件桥投递失败怎么办？**
A：事件停留在 `pending` 并自动重试，超 5 次置 `failed`。可在事件管理页手动重放。
