# 终端用户手册

本手册面向 LocalServe CLI 的终端使用者，覆盖智能补全、主题定制、性能优化（缓存 / 管道 / 优先级）、
别名 / 历史 / 分屏 / 会话持久化、AI 辅助等全部增强功能。基础命令（file / phys / nn / prompt / skill …）
见[使用说明](使用说明.md)与 `help`。

## 1. 快速开始

```bash
# 进入交互式 Shell（REPL）
localserve shell

# 一次性执行（与 REPL 同一套内核）
localserve version
localserve file list .

# 环境自检：平台 / 色彩能力 / 内存占用
localserve shell doctor
```

REPL 提示符格式（可在 `theme set prompt` 定制）：`{cwd} {symbol} {clock}` —— 工作目录、
命令符号（`❯` / 失败变红 `✗`）、可选时钟。

### 退出与恢复

- `exit` / `quit` / `Ctrl+D` 正常退出（会话标记为干净，下次启动不提示恢复）；
- 意外关闭（进程被杀 / 断电）后再次 `localserve shell` 会检测到崩溃标记，自动询问是否恢复
  命令历史、工作目录与环境变量（也可 `localserve shell --resume` 直接恢复）；
- `session status` 查看当前会话状态，`session drop` 丢弃存档，`session resume` 手动恢复。

## 2. 命令自动补全

交互输入时按 `Tab` 触发补全弹层，`↑/↓` 选择，`Enter` 采纳，`Esc` 关闭。

| 补全维度 | 说明 |
|---|---|
| 命令 + 别名 | 模糊匹配（`the` → `theme list`），历史用过的命令按「使用次数 + 新近度」排序，描述标注 `历史 · 用过 N 次` |
| 选项 | 列出当前命令声明过的选项与说明；`--flag=` 内联值也支持 |
| 选项值 | 有枚举语义的选项给出候选（如 `--format` 的取值） |
| 文件路径 | 相对路径（基于当前工作目录）与绝对路径均可；目录候选自动补 `/` |
| 管道段 | `&&` / `\|\|` / `;` / `\|` 之后的段重新从命令层补全 |
| 未知命令 | 自动退化为路径补全，不中断输入 |

预览弹层最多显示 8 行，超出时提示「… 共 N 条候选」；选中项带 `▸` 标记。

### 自定义补全规则

规则持久化在 `.cli/completions.json`（工作区状态目录），两种类型：

```json
[
  { "command": "file write", "position": 1, "type": "fixed", "candidates": ["./out/report.md", "./logs/today.log"] },
  { "command": "file read",  "flag": "encoding", "type": "fixed", "candidates": ["utf-8", "gbk"] }
]
```

- `position`：第几个参数（从 1 开始）；
- `flag`：选项名（为该选项的值提供候选）；
- `type: "path"`：交给内置路径补全。

## 3. 主题与界面定制

```bash
theme list                 # 内置 6 套主题：starlight / paper / solar-dawn / mono-pro / ember / forest
theme use ember            # 切换主题（持久化）
theme show --json          # 查看当前主题全部角色色
```

### 12 个颜色角色

`Foreground` / `Background` / `Cursor` / `PromptAccent` / `CommandEcho` / `Error` / `Warning` /
`Success` / `Comment` / `Highlight` / `Border` / `SelectionBackground`。

```bash
theme set prompt-accent #88c0d0     # 改角色色（#RRGGBB 或 #RGB）
theme set cursor-color #ff6600      # 光标颜色（cursor 本身是光标样式配置键，颜色用 cursor-color）
```

### 配置键（窗口 / 字体 / 光标）

```bash
theme set font "JetBrains Mono"     # 字体族
theme set font-size 15              # 字号（8–48）
theme set line-height 1.4           # 行高（0.8–3.0）
theme set opacity 0.92              # 窗口透明度（0.1–1.0，配合支持透明的终端模拟器生效）
theme set padding 2                 # 内容边距（列）
theme set cursor bar                # 光标样式：block / bar / underline
theme set cursor-blink false        # 光标闪烁
theme set show-clock true           # 提示符时钟
theme set prompt "{cwd} {symbol}"   # 提示符模板
```

### 导出配置档

```bash
theme export-profile wt      # Windows Terminal 片段
theme export-profile iterm2  # iTerm2 配色片段
theme export-profile text    # 纯文本对照表
```

色彩自动降级：TrueColor → 256 色 → 16 色 → 无色（重定向 / `NO_COLOR` 环境变量 / `--no-color` 时自动禁用 ANSI）。

## 4. 性能优化

### 解析引擎

命令选项规格表进程内缓存 + 无 LINQ 快路径定位命令。常用命令热路径解析耗时较旧实现
降低 ≥30%（见 `ParserPerfTests` 的冷/热基线断言）。

### 结果缓存

```bash
cache stats         # 命中 / 未命中 / 失效次数与条目数
cache clear         # 手动清空（REPL 与一次性命令共享同一实例）
cache ttl 120       # 修改 TTL（秒，持久化到 .cli/cache.config.json）
```

- 只缓存**只读安全命令**（白名单：help / version / file list / read / stat / hash / search 等）；
- 缓存键 = 命令行 + 工作目录 + 工作区根目录（`cd` 换目录后自动区分）；
- **语义失效**：任何非白名单（写类）命令成功执行后整表失效，杜绝读到过期结果；
- 管道命中时下游以 `[cache]` 标记提示；`--no-cache` 启动 REPL 可整体关闭。

### 管道与组合

支持 `&&`（成功链）、`||`（失败回退）、`;`（顺序）、`|`（真管道，上游 stdout 作为下游 stdin）：

```bash
file write ./report.md --content "hello" && file read ./report.md
version || echo "版本查询失败"
phys simulate --preset collision | file write ./frames.json
```

- `&&` 失败短路时输出「（&& 短路：跳过后续 N 段）」提示；`||` 成功短路安静跳过；
- 引号内的连接符不参与切分；`time <命令>` 前缀自动计时。

### 后台任务与优先级

```bash
--priority low phys simulate --preset nbody     # 后台低优先级（BelowNormal）
--priority high version                          # 后台高优先级（仅 Windows 支持 AboveNormal，其余平台忽略）
jobs             # 任务列表
jobs wait <id>   # 等待完成
jobs kill <id>   # 终止（整棵进程树）
```

后台任务以独立子进程运行，优先级映射：`low → BelowNormal`、`high → AboveNormal`（Linux/macOS 无对应档位时静默降级）。

## 5. 实用功能

### 命令历史

```bash
history list --since 2026-10-01 --kind cli --exit 0 --limit 20   # 多维筛选
history frequent                                                 # 按使用频度聚合（含失败率 / 平均耗时）
history search "^file .*--json" --limit 10                       # 正则搜索
history export ./hist.jsonl   # 导出（jsonl / json / csv）
history import ./hist.jsonl   # 导入（按记录 Id 去重）
history clear
```

### 别名

```bash
alias add gl "file list"            # 永久别名（持久化 .cli/aliases.json）
alias add tmp "version" --temp      # 临时别名（仅本会话）
alias add file "file list"          # 与注册命令同名 → 拒绝（--force 可覆盖）
alias rename tmp temp2
alias test gl .                     # 试运行别名
alias list / alias remove gl
```

别名展开支持递归（别名指向别名），深度上限 8；检测到环时放弃展开并原样执行。

### 分屏

```bash
pane split h     # 水平分屏（新窗格独立会话：工作目录 / 历史 / 环境变量）
pane split v     # 垂直分屏
pane next        # 切换活动窗格
pane select <id> / pane close <id> / pane show
```

窗格布局（方向 + 各窗格工作目录与历史）随会话持久化，`shell --resume` 时一并恢复；
最后一个窗格受保护，不可关闭。

## 6. 跨平台行为

| 平台 | 说明 |
|---|---|
| Windows 10/11 | 自动启用 VT 序列（conhost 需 P/Invoke 开启）；`--priority high` 生效 AboveNormal |
| macOS 12+ | 原生 ANSI；优先级降级为普通档 |
| Ubuntu 20.04+ / Fedora 34+ / Debian 11+ | 原生 ANSI；TERM/COLORTERM 探测色彩档位 |

统一约束：内存占用 ≤100MB、空闲 CPU <5%（`shell doctor` 输出当前进程内存实测值）；
所有输出在重定向 / `NO_COLOR` 下自动纯文本，脚本与 CI 无需特殊处理。

## 7. 错误诊断与帮助

- 命令失败时 REPL 自动弹出**诊断框**：错误分类、原因分析与可操作建议
  （沙箱越界 / 路径不存在 / 权限 / 用法 / 超时 / 网络等规则库 + 退出码兜底）；
- `--no-diagnose` 启动 REPL 可关闭；
- `help` 全局帮助，`help <命令>` 命令级帮助（含参数说明与使用示例）；
- 每条命令的执行日志持久化在 `.cli/command-history.jsonl`（可 `history export` 分析），
  审计日志在 `.cli/audit.jsonl`。

## 8. AI 助手

AI 能力经 AI 网关（`ai status` 查看健康状态）；网关不可用时自动回退到离线词表 /
规则引擎，功能不中断：

```bash
ai suggest "列出当前目录下所有 json 文件"     # 自然语言 → 命令（AI 与离线词表双源）
ai explain --last                             # 解释上一条命令的执行结果
ai explain "file list ."                      # 解释指定命令
ai fix --last                                 # 基于上一条失败输出给修复建议
ai tips                                       # 个性化建议：高频命令 → 建议别名；高失败率 → 建议 help；长耗时 → 建议后台
```

`ai suggest` 输出标注来源：`[AI 生成]` / `[离线词表]` / `[AI+规则]`。

## 9. 常见问题

**Q：Tab 补全在重定向脚本里不生效？**
补全与行编辑是交互能力，stdin 重定向时自动退化为逐行读取（脚本模式），属预期行为。

**Q：主题颜色没变化？**
终端模拟器需支持对应色彩档位（Windows Terminal / iTerm2 支持 TrueColor）；
conhost 旧控制台最高 16 色。`shell doctor` 查看实际探测结果。

**Q：缓存返回了旧结果？**
白名单只含只读命令，且写命令成功后自动整表失效。若手动改动了工作区外部文件，
执行 `cache clear` 或缩短 `cache ttl`。

**Q：`cd` 之后补全的路径还是旧目录？**
不会。路径补全基于进程当前工作目录，REPL 的 `cd` 真实生效；缓存键也包含工作目录。

**Q：别名与命令同名会怎样？**
默认拒绝（防误覆盖），确需覆盖加 `--force`；别名展开首 token 指向自身时按环处理，原样执行。

**Q：会话恢复包含哪些内容？**
命令历史、每个窗格的工作目录与输入历史、环境变量、分屏布局。正常退出后存档标记干净，
下次启动不再提示；崩溃后启动时提示恢复。

**Q：AI 功能必须联网吗？**
否。网关健康时用 AI 增强；离线时 `ai suggest` 回退离线词表、`ai explain` 回退结构摘要、
`ai fix` 回退规则引擎（错误诊断始终可用，因为它不依赖 AI）。
