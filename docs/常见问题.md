# 常见问题（FAQ）

## 安装与启动

**Q1：`dotnet build` 报 SDK 版本不匹配？**
本项目需要 .NET 10 SDK（`global.json` 约束）。执行 `dotnet --version` 确认；SDK 下载见 <https://dotnet.microsoft.com/download>。根目录的 `global.json` 允许 10.0 及以上 patch 版本。

**Q2：端口 5100 被占用怎么办？**
用环境变量改监听地址后启动：
```bash
# PowerShell
$env:ASPNETCORE_URLS="http://localhost:5200"; dotnet run --project src/LocalServe.Api
# Bash
ASPNETCORE_URLS=http://localhost:5200 dotnet run --project src/LocalServe.Api
```

**Q3：启动后页面空白或静态资源 404？**
前端产物在 `src/LocalServe.Api/www/` 下，确认从仓库完整拉取（`index.html` 约 480 KB）。若需从 `.nexus/` 源重新装配，需要 Node.js ≥ 18：`node .nexus/build.mjs`。

## 账号与安全

**Q4：收不到验证码 / 验证码失效？**
验证码有冷却时间与窗口期限制，并有防爆破计数。检查日志中的发送记录；开发环境可查看服务端控制台输出。多次失败会临时锁定，稍后重试。

**Q5：401 ADMIN_REQUIRED / PERMISSION_DENIED 是什么意思？**
权限分级：401 未登录或 token 失效；`ADMIN_REQUIRED` 需要管理员角色；`PERMISSION_DENIED` 已登录但缺少该操作权限点。管理端（`api/admin/**`）与用户端硬隔离。

**Q6：反向代理后客户端 IP 全是代理地址？**
默认不采信 `X-Forwarded-For`（防伪造）。确有可信代理时设置 `TRUST_PROXY=1`。

## 物理模拟

**Q7：3D 页面显示「Three.js 加载失败」？**
Phys3D 通过公网 CDN 加载 Three.js，内网/离线环境不可达。解决：将 `three.min.js`（0.152.2）下载到 `www/` 并把 `phys3d.html` 中的 CDN `<script>` 改为本地引用。

**Q8：仿真会话找不到了？**
会话保存在内存中，TTL 2 小时，服务重启即清空。需要长期保留用 `GET /api/phys/sessions/{id}/frames` 导出 JSON/CSV。

**Q9：运行中可以改参数吗？**
可以。`POST /api/phys/sessions/{id}/control`，`action=set-param` 支持重力 / 空气阻力 / 时间步长 / 恢复系数，内存操作 <100ms。

**Q10：帧率达不到 30 FPS？**
减小 `timeStep`、缩短 `durationSeconds` 或减少刚体数量。碰撞检测宽相包围球已内置剔除；OBB/盒混合场景计算量大于纯球场景属预期。

## AI 与模型

**Q11：AI 对话报网关不可用？**
本地模型运行时依赖 Ollama（默认 `http://localhost:11434`）。未部署时对话能力降级，但技能启发式（parse / promptOptimize / codeCorrect）与全部物理技能离线可用。

**Q12：流式对话中刷新页面会扣费吗？**
会。SSE 流式断开时上游 token 已产出，按设计不退款（服务端注释与帮助文档均明示）。

## 数据与运维

**Q13：数据库在哪里，如何备份？**
SQLite 单文件，位置见 `localserve info --json` 的数据目录输出。备份用 CLI：`localserve backup run`（`VACUUM INTO` 一致性快照），保留策略自动清理旧备份。

**Q14：想把系统重置到初始状态？**
停止服务后删除数据目录中的 `.db` 文件，重启时 schema 幂等重建（带锁，多实例安全）。

**Q15：测试跑不过怎么办？**
1. 确认 .NET 10 SDK；2. `dotnet test localserve.slnx` 查看具体失败集；3. Windows 特有编码问题优先检查系统区域设置。提交 issue 时请附完整失败输出与环境信息（OS / SDK 版本）。

## CLI

**Q16：`cmd run rm ...` 被拒绝？**
危险命令黑名单一律拒绝（退出码 4），这是安全设计。白名单查询：`localserve cmd allowlist --json`，策略原因：`localserve cmd policy rm`。

**Q17：CLI 与 API 行为不一致？**
不应该出现——两者调用**同一份** Core 实现。若遇到请附复现命令提 issue，这是最高优先级缺陷。
