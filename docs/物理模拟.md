# 物理模拟模块 — 架构与使用指南

> Phase 1 已交付：物理内核 + 电机 + 材料 + 会话管理 + 6 条 AI 技能 + REST + CLI + .nexus 可视化页。
> 纯 C# 实现（`LocalServe.Core.Physics`，零第三方依赖），`dotnet test` 全绿（283 用例）。

## 1. 模块结构（低耦合 · 单一职责）

```
src/LocalServe.Core/Physics/
├─ Vector3 / Quaternion / CoordSystem   # 数学基座：向量、四元数姿态、笛卡尔/球/柱坐标互转
├─ Mechanics.cs                          # 纯静态力学库：重力/库仑摩擦/胡克定律(4种曲线)/应力集中/扭矩/冲量碰撞
├─ Motors/       IMotor + MotorModels(Dc/Stepper/Servo/Bldc) + MotorFactory + MotorLibrary
├─ Materials/    IMaterialModel + MaterialCatalog(10类×5型号) + MaterialComposer(3种组合) + 温度相关性
├─ Engine/       Scene(半隐式欧拉积分) + CollisionDetector(球/盒,冲量法) + Constraints(8种) + Timeline(力时间曲线)
├─ PhysConfig.cs # DTO + PhysConfigValidator(范围/类型/依赖校验)
├─ PhysSimulationManager.cs # 有状态会话：ConcurrentDictionary + TTL 2h + 会话级锁
└─ PhysSkills.cs # 6 条 AI 技能注册（与 REST/CLI 同链路）
```

## 2. 物理内核要点

| 项 | 实现 |
|---|---|
| 积分 | 半隐式欧拉（dt 默认 0.016s，可配 0.001–0.1s），谐振子能量有界（测试验证 <0.5% 漂移） |
| 姿态 | 四元数积分 `dq = 0.5·ω⊗q·dt` 后归一化，ZYX 欧拉角互逆换算 |
| 碰撞 | 宽相包围球 + 窄相（球球 / 球盒 / 盒盒），冲量法响应（动量守恒 + 恢复系数 0–1） |
| 约束 | 固定 / 铰链 / 滑轨 / 绳索 / 弹簧 / 球窝 / 万向 / 平面，共 8 种，位置式求解 |
| 力曲线 | 阶跃 / 正弦 / 三角 / 自定义折线（StartTime 门控 + 分段线性插值） |
| 电机 | DC 一阶电气+机械方程（空载转速自然涌现）；步进电机整数步计数器（无浮点累积漂移）；伺服 P 控制 ±0.1°；一阶热模型 + 能耗积分 + 8 种故障（堵转/过流/过热/欠压/编码器/轴承/绕组短路/超速） |
| 材料 | 10 类 × 5 型号；温度相关性 -50~150°C 线性折减；组合方式 层叠/混合/框架-填充（Hashin-Shtrikman 下界） |

## 3. AI 技能（AI 工作台直接调用）

| 技能 | 动作 | 说明 |
|---|---|---|
| `phys.simulate` | — | 创建并运行仿真：`{ config, seconds? }`，非法配置返回 400+逐条原因 |
| `phys.session` | list/get/step/run/reset/remove/frames | 会话管理；frames 抽样导出轨迹（≤500 帧） |
| `phys.motor` | list/simulate | 选型查询；PWM 驱动仿真（故障注入、抽样 ≤100 点） |
| `phys.material` | list/get/sample/combine | 材料目录 / 温度采样 / 复合组合 |
| `phys.analyze` | — | 逐刚体合力/力矩/正压力/平衡判断（材料摩擦关联） |
| `phys.control` | pause/resume/set-param | 运行中实时调参（重力/空气阻力/时间步长/恢复系数/碰撞迭代/自适应子步/摩擦开关/CCD 阈值，内存操作 <100ms） |

**增强参数（v2 起，技能 / REST / CLI / Editor 全链路可用）**：

| 字段 | 范围 | 默认 | 说明 |
|---|---|---|---|
| `collisionIterations` | 1–3 | 2 | 碰撞求解迭代次数，越高多体堆叠越稳定 |
| `maxSubsteps` | 1–8 | 4 | 自适应子步上限，高速物体自动细分防穿透（CCD） |
| `enableFriction` | bool | true | 库仑摩擦切向冲量开关（`friction` 真正生效） |
| `ccdThreshold` | >0（≤1000） | 0.5 | CCD 速度阈值 m/s，单步位移超过 阈值×最小碰撞体尺度 时触发子步 |
| `bodies[].angularDamping` | 0–1 | 0 | 角速度阻尼，每步按 1−angularDamping 衰减 |

实时调参 `phys.control set-param` 亦支持 `collisionIterations / maxSubsteps / enableFriction / ccdThreshold`。

调用示例（内部任意宿主）：
```json
{ "skill": "phys.simulate", "input": { "config": { "gravity": 9.81, "durationSeconds": 1.0,
  "bodies": [ { "id": "ball", "mass": 1, "position": [0,0,10],
                "material": "steel.45", "shape": { "type": "sphere", "radius": 0.1 } } ] } } }
```

## 8. Phase 2 开发文档

### 8.1 GJK + OBB 碰撞检测（`Engine/Gjk.cs`）

**算法链路**（需求点名 GJK）：

```
宽相（包围球剔除）→ GJK 布尔判交 → MTV 按类型解析计算 → 冲量响应
```

| 环节 | 实现 |
|---|---|
| GJK 判交 | `GjkEpa.Overlaps(mink, out simplex)`：Minkowski 差支撑函数 + 单纯形迭代（上限 32 次，单次封闭代数运算 <1ms）；`along < 1e-10` 判接触 |
| MTV（最小平移向量） | 按碰撞对类型解析计算，退化对称情形数值稳健 |
| EPA | `GjkEpa.Penetration` 仅作为**自定义 ICollider 插件**的通用兜底（球/盒/OBB 均走解析路径） |

**MTV 解析规则**：

| 碰撞对 | 方法 |
|---|---|
| 球-球 | 中心连线方向，深度 = rA+rB−d |
| 球-凸（盒/OBB） | 局部系最近点 clamp 法；球心在盒内时沿最浅穿透轴推出 |
| 凸-凸（含 AABB 与 OBB 混合） | SAT 分离轴定理：15 轴 = 3+3 面轴 + 9 边叉积轴，最小重叠轴为接触法线 |

**新增碰撞体**：`ObbCollider(Center, HalfExtents, Rotation)` —— 支持任意旋转姿态的盒体，
`Rotation` 跟随刚体四元数（`Scene.MoveCollider` 统一位姿同步）；`WorldAabb` 由 8 角点旋转包络。

**配置写法**（`shape.type = "obb"`，半尺寸复用 `halfExtents`，姿态用 `orientationEulerDeg`）：

```json
{ "id": "box", "mass": 1, "position": [0,0,1], "orientationEulerDeg": [0, 0, 45],
  "shape": { "type": "obb", "halfExtents": [0.5, 0.1, 0.1] } }
```

### 8.2 S-N 完整疲劳模型（`Materials/Fatigue.cs`）

三段式疲劳评估链路（纯静态、零依赖，与 `IMaterialModel.SampleAt(temp)` 温度采样组合）：

| 环节 | 公式 |
|---|---|
| Basquin S-N 曲线 | σ = σf·(N/N0)^(−b)；反解 N(σ) = N0·(σ/σf)^(−1/b) |
| 耐久极限截断 | σe = EnduranceRatio·σf（默认 0.35，钢类）；σ ≤ σe → 无限寿命 |
| Goodman 平均应力修正 | σa,eq = σa / (1 − σm/σuts)；σm ≤ 0 不折减；σuts 缺省 1.5·σy |
| Miner 线性损伤累积 | D = Σ nᵢ/Nᵢ(σᵢ)；D ≥ 1 破坏；预测寿命 = 1/D |

**核心 API**：

```csharp
var sn = SnParameters.FromMaterial(material.SampleAt(150), enduranceRatio: 0.35);
FatigueAnalysis.CyclesToFailure(sn, stressMPa);          // 单级 S-N 反解
FatigueAnalysis.GoodmanAmplitude(ampl, mean, uts);       // 平均应力修正
FatigueAnalysis.Accumulate(sn, [new FatigueLoad(280, 500_000), ...]);  // 谱分析 → FatigueResult
FatigueAnalysis.Evaluate(model, tempC, spectrum, meanStressMPa: 0);    // 一站式（含温度采样+Goodman）
```

`FatigueResult` 含逐级明细 `Breakdown`（应力级 / 循环数 / Nf / 贡献占比），支撑 AI 结果查询接口。

### 8.3 软体形变模拟（`Engine/SoftBody.cs`）

spring-mass 有限元简化模型（FEM 近似）：

- **离散**：`SoftBody.BoxGrid(center, halfExtents, divisions, totalMass, stiffness)` 生成长方体点阵，
  6 邻域结构键 + 面内对角剪切键连接（±x/±y/±z + 面对角线），每节点均分质量。
- **弹性形变**：胡克定律 + 轴向阻尼 F = k·(L−L0) + c·v_rel，对称施加于弹簧两端。
- **断裂（裂纹扩展离散近似）**：每根弹簧独立判定拉伸应变 (L−L0)/L0 > BreakStrain（默认 0.5）→ 破断
  （仅拉伸断裂，压缩不误断）；`ResidualStiffnessRatio` 控制断后残余刚度（默认 0 = 完全断开）。
- **积分**：半隐式欧拉（与 Scene 一致，能量有界）；`TotalEnergy()` 供能量守恒诊断。
- **Pinned 节点**：夹持端/固定端不积分（悬臂梁、拉伸试验场景）。

```csharp
var beam = SoftBody.BoxGrid(Vector3.Zero, new Vector3(1, 0.1, 0.1), new Vector3Int(10, 2, 2),
    totalMass: 2, stiffness: 2000, breakStrain: 0.3);
beam.Nodes[0].Pinned = beam.Nodes[1].Pinned = true;  // 一端夹持
beam.Run(2.0, dt: 0.004);
```

### 8.4 温度场耦合（Scene 内建）

**演化模型**（每步按序执行，帧快照 `SceneFrame.Temperatures` 带出）：

| 机制 | 公式 | 配置 |
|---|---|---|
| 牛顿冷却 | dT/dt = −rate·(T − T_ambient)，显式欧拉积分 | `ambientTempC`（-50~150，默认 20）、`heatTransferRate`（0~1 1/s，默认 0.02，0 = 关闭） |
| 碰撞生热 | ΔE = ½·m_eff·v_rel²·(1−e²) → ΔT = ΔE·(mᵢ/M)/(mᵢ·c) | `specificHeat`（J/(kg·K)，默认 460 钢） |

- 初温：body 级 `temperatureC`（-50~150，默认 20）。
- 联动链路：碰撞生热/冷却 → `body.TemperatureC` → `IMaterialModel.SampleAt(T)` → 疲劳/模量/屈服等
  温度相关属性（`FatigueAnalysis.Evaluate` 已打通；场景内材料属性消费按需扩展）。
- 校验：场景级 `ambientTempC`/`heatTransferRate` 与 body 级 `temperatureC` 均纳入 `PhysConfigValidator`。
