# 安装指南

本文档介绍如何在本机获取、构建并运行 starAItable（LocalServe 后端 + Nexus 前端 + CLI）。

## 1. 环境要求

| 组件 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11、Linux、macOS | 任意支持 .NET 10 的系统 |
| .NET SDK | **10.0** 及以上 | 构建/运行/测试的唯一硬依赖；验证版本 10.0.401 |
| Node.js（可选） | ≥ 18 | 仅在需要重新装配前端（`node .nexus/build.mjs`）时使用；运行不依赖 |
| Ollama（可选） | 任意近期版本 | 本地大模型运行时（默认 `http://localhost:11434`），不装则 AI 对话能力降级 |
| Docker（可选） | ≥ 20 | 仅命令沙箱 docker 后端与 agentcluster 容器化部署需要 |

> 验证 .NET SDK：`dotnet --version` 输出 `10.0.x` 即可。

## 2. 获取源码

```bash
从 starAItable 官方下载站获取最新客户端/服务端安装包：
- 下载页：https://barrie-fly.github.io/star-ai-table-local/download.html
- 文档中心：https://barrie-fly.github.io/star-ai-table-local/docs.html
```

或从 GitHub 下载源码包解压。

## 3. 构建

```bash
dotnet build localserve.slnx
```

预期结果：`0 个错误`（警告可忽略）。解决方案构成：

```
src/LocalServe.Core     领域核心库（零第三方依赖）
src/LocalServe.Api      Web 宿主（ASP.NET Core，含 Nexus 前端静态产物 www/）
src/LocalServe.Cli      命令行宿主（localserve）
tests/*                 Core / Api / Cli 三套 xUnit 测试
```

## 4. 运行测试（建议）

```bash
dotnet test localserve.slnx
```

三套测试全绿即环境就绪。任何失败请先确认 .NET SDK 版本，再参考[常见问题](常见问题.md)。

## 5. 启动 Web 服务

```bash
dotnet run --project src/LocalServe.Api
```

- 默认监听 `http://localhost:5100`（launchSettings）；
- 浏览器打开 <http://localhost:5100> 即进入 **Nexus AI 集成工作台**（首次使用先注册账号）；
- 3D 物理可视化独立页：<http://localhost:5100/phys3d.html>（也可从工作台「物理模拟」页的 🧊3D 可视化按钮进入）。

### 常用环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `ASPNETCORE_URLS` | `http://localhost:5100` | 监听地址/端口 |
| `LOCALSERVE_SCHEDULER` | 未设置（关） | 置 `1` 启用自动化调度循环 |
| `TRUST_PROXY` | 未设置 | 反向代理后置 `1` 以采信 `X-Forwarded-For` |
| `LOCALSERVE_DATA_DIR` | 程序数据目录 | SQLite 与状态文件落盘位置（见 `dotnet run --project src/LocalServe.Cli -- info --json`） |

## 6. 命令行宿主（CLI）

```bash
# 端到端自检（部署健康检查，14 项）
dotnet run --project src/LocalServe.Cli -- selftest

# 工作区 / 沙箱 / 能力清单（机器可读）
dotnet run --project src/LocalServe.Cli -- info --json

# 物理仿真一键体验（内置预设）
dotnet run --project src/LocalServe.Cli -- phys simulate --preset spring --seconds 2
```

发布为单文件可执行（可选）：

```bash
dotnet publish src/LocalServe.Cli -c Release -r win-x64 --self-contained false -o publish/cli
```

## 7. 卸载

删除源码目录与数据目录即可；SQLite 数据库为单文件，备份/迁移见[部署运维](部署运维.md)。
