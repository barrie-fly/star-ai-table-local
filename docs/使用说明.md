# 使用说明

本手册面向最终用户，介绍 starAItable 工作台（Web UI）、3D 物理可视化与 CLI 的日常使用。

## 1. 启动与登录

1. 启动服务：`dotnet run --project src/LocalServe.Api`（见[安装指南](安装指南.md)）；
2. 打开 <http://localhost:5100>，首次使用在登录页切换到注册，填写账号信息并完成邮箱验证码校验；
3. 登录后进入 **Nexus 四区外壳**：

| 区域 | 内容 |
|---|---|
| 顶栏 | 品牌 / 面包屑 / 环境状态点 / 命令面板 `Ctrl+K` / 助手开关 `Ctrl+B` / 通知 / 用户菜单 |
| 导航轨 | 10 组 32 项视图入口 |
| 工作区 | 当前视图内容 |
| 助手停靠面板 | AI 助手对话与快捷指令（窄屏自动收起为抽屉） |

快捷键：`Ctrl+K` 命令面板 · `Ctrl+B` 助手面板 · `Esc` 关闭浮层。

## 2. 物理模拟（工作台内）

入口：导航轨 →「物理模拟」。

1. **选预设**：右侧「场景预设」面板提供自由落体 / 弹簧振子 / 弹性碰撞等内置场景（预设即 `/api/phys/simulate` 的 JSON 配置）；
2. **运行**：点「运行仿真」——多刚体动力学（半隐式欧拉 + 四元数姿态 + 冲量碰撞 + 8 种约束）开始计算；
3. **回放**：等轴投影 Canvas 逐帧回放，`▶ 回放` / `⏸ 暂停` 控制，轨迹与速度箭头同步显示；
4. **进阶**：电机速查（4 类电机模型与 PWM 仿真）、材料速查（10 类 × 5 型号，支持温度采样与复合材料组合）。

## 3. 物理模拟 3D 可视化（Phys3D）

入口：物理模拟页 →「🧊 3D 可视化」按钮，或直接访问 `/phys3d.html`。

| 功能 | 操作 |
|---|---|
| 运行新仿真 | 顶栏选预设（含方块堆叠、OBB 旋转翻滚）→「▶ 运行新仿真」 |
| 历史会话回放 | 「— 选择会话 —」下拉载入已完成的仿真（会话 TTL 2h） |
| 相机 | 左键拖动旋转 · 滚轮缩放 · 右键平移；侧栏提供复位/俯视/正视/侧视 |
| 光照 | 环境光 / 方向光 / 点光源强度与点光色实时可调 |
| 轨迹 | 显示开关、线宽 1–4、抽样密度 1/1–1/20 |
| 受力 / 速度箭头 | 显示开关 + 比例缩放，力按大小颜色编码 |
| 图表 | 右栏实时曲线：速度 \|v\|、温度、受力 \|F\|（逐物体可勾选） |
| 回放控制 | 播放/步进/拖动进度条；0.25×–4× 倍速与循环开关 |
| 数据导出 | CSV（逐帧物理量）、JSON（完整帧历史） |
| 录制 | 「● 录制」将 3D 视口录为 WebM 视频（浏览器 MediaRecorder，录制中按钮高亮） |

> 3D 页依赖 CDN 加载 Three.js；离线环境会显示明确的「Three.js 加载失败」提示页。

## 4. AI 调用（技能接口）

物理能力通过 **6 条 `phys.*` 技能**暴露给 AI 工作台 / REST / CLI（三链路同源校验 + 审计）：

| 技能 | 用途 |
|---|---|
| `phys.simulate` | 自然语言/结构化配置创建并运行仿真 |
| `phys.session` | 会话管理（list/get/step/run/reset/frames） |
| `phys.motor` | 电机选型与 PWM 驱动仿真（故障注入） |
| `phys.material` | 材料目录 / 温度采样 / 复合组合 |
| `phys.analyze` | 逐刚体合力/力矩/正压力/平衡判断 |
| `phys.control` | 运行中实时调参（重力/空气阻力/步长/恢复系数） |

REST 调用示例：

```bash
curl -X POST http://localhost:5100/api/phys/simulate \
  -H "Content-Type: application/json" \
  -d '{ "config": { "gravity": 9.81, "durationSeconds": 1.0,
        "bodies": [ { "id": "ball", "mass": 1, "position": [0,0,10],
                      "material": "steel.45", "shape": { "type": "sphere", "radius": 0.1 } } ] } }'
```

## 5. 文件工具（FileTools）

导航轨「工具与技能」或 REST `api/filetools/**`：编码检测/转换（GBK、UTF-16 等）、文件加解密（对称/ RSA 混合/哈希）、压缩包创建/解压（zip / tar.gz，支持密码）、网络分包构造/解析/拆分合并。长任务经 `jobs` 端点轮询，操作留痕 `logs`。

## 6. 神经网络与集群协同

- 「神经网络模拟」视图：网络结构、神经元激活状态与参数变化的实时可视化，模型加载/训练/优化全流程可监控；
- 「Agent 编队」「数据总线」「工作流编排」视图：多 AI 集群通信拓扑、数据流向与任务编排的可视化，支持项目统筹（进度跟踪 / 资源分配 / 模块依赖）。

## 7. CLI 常用命令

```bash
localserve phys materials --id steel.45 --temp-c 150   # 材料温度采样
localserve phys analyze --preset collision             # 受力分析
localserve file convert a.txt txt->upper               # 文件域：10 种格式转换
localserve cmd run git status                          # 命令域：白名单执行
localserve skill invoke ai.parse --set 'content={"a":1,}'  # AI 启发式（离线可用）
localserve backup run                                  # 数据库一致性备份
```

退出码契约：`0` 成功 · `1` 一般错误 · `2` 用法错误 · `3` 未找到 · `4` 危险命令拒绝 · `70` 内部错误。

## 8. 创作台

- **矢量编辑器**：`__ve` 命令总线接入 AI 面板，产物一键入库为 SVG 全文；
- **电路模拟设计**：SPICE 网表导出 + Ollama 本地诊断（未连接时降级为内置规则引擎）；
- **音视频工作室**：`__av` 命令总线，素材入库为 base64。

所有创作产物写入工作区 `nexus/artifacts/`，AI 面板与快捷指令经统一命令总线驱动。
