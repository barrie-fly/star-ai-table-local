# 神经网络模拟模块

> 纯 C# 零依赖实现的多架构神经网络训练引擎：内联式 AI 助手（nn.\* 技能）、实时可视化、
> 项目统筹板、混合训练（本地 CPU + agentcluster 集群转发）、检查点可复现。
> **v2.3.1 增强**：图拓扑层、自定义层注册、DDP 数据并行、早停/梯度裁剪/学习率调度、
> 多模态预处理、多维评估/可解释性、模型对比、内存护栏、交互式可视化。

- **可复现**：种子贯穿参数初始化、数据集生成、每轮打乱；同配置同种子历史逐位一致。

## 增强功能详解

### 自定义层注册（REST / CLI 双入口）

```
POST /api/nn/custom-layers            { "type": "activation:swish2" }
POST /api/nn/custom-layers            { "type": "composite:block", "layers": [...] }
GET  /api/nn/custom-layers            # 内置 + 自定义列表
```

- `activation:{name}`：注册后作为激活层使用，激活名不再受内置列表限制。
- `composite:{name}`：把一组层配置封装为组合层，注册后可直接在 `layers` 中引用。
- 进程级注册表 `CustomLayerRegistry`：内置层不可覆盖，重复注册抛异常，未知类型返回 null（fail-closed）。

### 图拓扑层（GraphLayer）

```json
{ "type": "graph", "graph": { "nodes": [
  { "id": "a", "type": "dense", "units": 3, "activation": "relu" },
  { "id": "b", "type": "dense", "units": 5, "activation": "tanh" },
  { "id": "out", "type": "dense", "units": 1, "inputs": ["a", "b"] }
] } }
```

- Kahn 拓扑排序保证前向按拓扑序、反向按逆拓扑序执行。
- 并行分支梯度累加、多输入拼接切分。
- 环检测与缺失节点引用在构造期抛异常（fail-closed）。

### DDP 分布式数据并行

```
POST /api/nn/sessions   { "config": { ..., "ddp": { "workers": 2, "backend": "sync" } } }
CLI  nn ddp --file ddp-config.json --wait true --json
```

- 数据集按 worker 数分片，每 worker 独立前向/反向**累积梯度**（不 Step）。
- epoch 边界 AllReduce 梯度平均 → 主优化器统一裁剪 + Step → sync 后端参数广播。
- `FallbackOnError` 在 worker 配置非法时降级为单 worker。
- 快照扩展字段：`workers` / `ddpBackend` / `earlyStoppingBadEpochs` / `gradNorm` / `validationCount`。

### 早停 / 梯度裁剪 / 学习率调度

```json
{
  "earlyStopping": { "monitor": "val_acc", "patience": 5, "minDelta": 0.001, "restoreBest": true },
  "gradientClipNorm": 1.0,
  "lrScheduler": { "type": "step", "stepSize": 30, "decayFactor": 0.5 }
}
```

- 早停支持 `loss/acc/val_loss/val_acc`；无验证集时 val_monitor 降级用训练集指标，避免伪早停。
- 梯度裁剪返回裁剪前范数，`ClippedNorm` 暴露裁剪后实际范数供监控。
- 学习率调度器在每 epoch 结束后由训练器调用，`plateau` 依据损失自适应。

### 数据预处理与自动特征工程

```json
{
  "preprocess": {
    "normalize": "zscore", "oneHot": true, "pcaComponents": 4,
    "augmentation": "mixup", "augmentStrength": 0.2, "trainSplit": 0.8
  }
}
```

- `TrainSplit` 划分验证集，早停 val_monitor 直接消费。
- CLI `nn autofeature --csv-file features.csv --feature-count 3 --threshold 0.01` 输出保留/剔除特征索引。

### 评估、可解释性与模型对比

- 分类：混淆矩阵 / Precision / Recall / F1 / 宏平均 / AUC；回归：MAE / RMSE / R²。
- 显著图：对输入求损失梯度绝对值归一化；置换重要性：逐特征洗牌观察指标下降。
- 前端「模型对比」面板粘贴多配置 JSON → 并行训练 → 排序表格。

### 内存护栏与会话健康

- `NnSessionManager(maxMemoryBytes: ...)`：创建时基于 `Estimate()` 估算内存，超限拒绝创建。
- `Health()` 暴露 `MaxMemoryBytes / TotalMemoryBytes / ActiveSessions / SessionSlotsRemaining / AvgGradNorm`。

## 会话生命周期

`Created → Training ⇄ Paused → Completed / Stopped / Error`

- 训练在 `TaskCreationOptions.LongRunning` 线程执行，暂停 / 恢复 / 停止 / 热更新参数在 epoch 边界生效。
- 会话 TTL 2 小时，过期自动回收；快照 History 环形上限 5000 条。
- DDP 模式下训练状态以 `Ddp.Epoch` 为准，避免轮询死循环。

## CLI 命令（`nn` 组）

```
nn create --dataset xor|circle|spiral|sine|sequence|moons [--file <config.json>] [--epochs N] [--seed N]
nn train --id <sessionId> [--epochs N] [--wait]
nn state --id <sessionId> [--viz] [--json]
nn control --id <sessionId> --action pause|resume|stop|set-param [--lr X] [--batch N] [--epochs N]
nn checkpoint --id <sessionId> --action save|load [--name <file>]
nn eval --id <sessionId> [--mode evaluate|predict] [--input <json>]
nn custom-layer --action list|register --type activation:x|composite:x [--file layers.json] [--json]
nn autofeature --csv-file <file> --feature-count N [--threshold X] [--json]
nn ddp --file <config.json> [--wait true] [--json]
nn remote --job <name> --dataset <id> [--model <id>] [--method lora|full] [--epochs N] [--lr X]
nn project --action list|submit|update|estimate [--name ...] [--task-id ...] [--state ...] [--progress X]
```

冒烟示例：

```
localserve nn create --dataset xor --epochs 300          # 33 参数 / 100 样本
localserve nn train --id <id> --wait                     # 阻塞至完成
localserve nn ddp --file ddp.json --wait true --json     # DDP 2 worker 训练
localserve nn custom-layer --action register --type activation:swish2
localserve nn autofeature --csv-file features.csv --feature-count 3
localserve nn state --id <id>                            # epoch / loss / acc / workers / badEpochs / gradNorm
localserve nn eval --id <id> --input "[1,0]"             # 单样本预测
```

## AI 技能（nn.\*，8 条，经 SkillRegistry 自动暴露给 Agent 集群）

`nn.create` / `nn.train` / `nn.control` / `nn.state` / `nn.checkpoint` / `nn.eval` / `nn.remote` / `nn.project`

技能入参带 JSON schema 校验与角色鉴权（member 可写、guest 只读），审计与 AI 技能同链路。

## 混合训练模式

- **小模型**（默认）：本地纯 C# CPU 引擎，秒级训练 XOR/螺旋/正弦等。
- **分布式**：`nn ddp` / 配置 `ddp.workers=N` 在 Core 内多线程数据并行。
- **大模型**：`nn.remote` 把 `{jobName, dataset, baseModel, method, epochs, learningRate}` POST 到
  agentcluster `POST /api/v1/ai/train/jobs`（202 返回 `taskId`），状态查询透传 `GET /api/v1/tasks/{taskId}`。
- **降级语义**：集群不可达不抛 5xx —— 提交返回 `available=false`，任务查询返回 503；本地训练不受影响。

## 配置写法（JSON）

```json
{
  "name": "XOR 拟合",
  "architecture": "mlp",
  "taskType": "classification",
  "inputShape": [2],
  "dataset": "xor",
  "seed": 42,
  "layers": [
    { "type": "dense", "units": 8, "activation": "tanh" },
    { "type": "dense", "units": 1, "activation": "sigmoid" }
  ],
  "optimizer": { "type": "adam", "learningRate": 0.05 },
  "lrScheduler": { "type": "step", "stepSize": 50, "decayFactor": 0.5 },
  "preprocess": { "trainSplit": 0.8, "normalize": "zscore" },
  "earlyStopping": { "monitor": "val_loss", "patience": 10, "restoreBest": true },
  "gradientClipNorm": 5.0,
  "epochs": 300,
  "batchSize": 8
}
```

- `architecture`：mlp / cnn / rnn / lstm / transformer（层序列才是真实结构，graph 节点亦可）。
- 形状在构建期逐层递进校验，不匹配立即报错（含逐条原因）。
- 自定义数据集：`samples: [{ input: [..], target: [..] }, ...]`。
